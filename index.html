How this works. A GitHub Actions job runs on a weekly schedule, calls the Claude API (with its web-search tool) to check each operator's interconnection-procedure and planning/study-guideline pages, and commits any new or revised documents into data/updates.json — which is what this page reads. "Recent" marks activity from roughly the trailing 12 months, not just items freshly added to this feed — a document stays tagged Recent until it ages past that window on a later check. Always confirm against the linked source before relying on a document for filings or engineering work — this feed is a change-detection aid, not a legal record.
